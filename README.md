# ArchiForge 3D v0.3

Профессиональная стартовая 3D-основа для архитектурного веб-редактора.

## Возможности
- выбор объектов
- стены с привязкой к сетке
- Shift для строгих горизонтальных/вертикальных стен
- Undo / Redo и Ctrl+Z / Ctrl+Y
- удаление объектов
- свойства и размеры
- материалы
- Home / Top View
- JSON Save и PNG
- русский / таджикский
- Web Audio UI click

Открой `index.html` через GitHub Pages. Three.js подключается через import map? В этой версии `app.js` ожидает доступность `three` и `three/addons`; если репозиторий использует CDN, добавь importmap в index.html с официальным CDN Three.js.
