# ArchiForge 3D v0.1.1

Двуязычная стартовая версия архитектурного 3D-веб-приложения.

## Языки
- 🇷🇺 Русский
- 🇹🇯 Тоҷикӣ

Переключатель языка находится в верхней панели. Выбор сохраняется в браузере через localStorage.

## Файлы
- `index.html` — структура приложения
- `style.css` — интерфейс
- `app.js` — 3D-сцена и логика
- `i18n.js` — система переводов
- `.gitignore`

## GitHub Pages
1. Создай новый repository.
2. Загрузи все файлы в корень.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, Folder: `/ (root)`.
6. Save.

## Важно
Three.js загружается с CDN, поэтому для работы нужен интернет.

## Что есть
3D-сцена, сетка, камера Orbit/Pan/Zoom, выбор объектов, свойства, размеры, координаты, материалы, удаление, вид сверху, сохранение JSON, экспорт PNG, русский/таджикский язык.

## Что будем делать дальше
Следующий крупный этап — v0.2: настоящий инструмент стен, точные размеры, привязка к сетке и создание архитектурных элементов мышью.
